# Lumina 拾光 — 用原生相機拍出美照的輔助 PWA

> 狀態：M0–M3 完成（2026-10-26）；下一步 M4 原生相機教練
> 定位：**拍照交給 iPhone 原生相機**，Lumina 只負責「拍前找光、選姿勢 → 拍時對位 → 拍後檢查」

## 1. 為什麼不自己做相機

| 面向 | 原生相機 | 網頁相機（getUserMedia） |
|---|---|---|
| 畫質 | 全解析度、HEIF/ProRAW | iOS Safari 常卡 720p |
| 人像模式 / 夜拍 / 多鏡頭 | 有 | 無；zoom constraint iOS 不支援 |
| 主畫面 PWA 穩定度 | — | iOS 26 有畫面轉 90° bug、歷史上多次失效 |

結論：MVP 完全不碰相機 API，純內容 + 工具型 PWA；對位取景器（③）列 P1，之後實機驗證再做。

## 2. 已拍板決策

| 項目 | 決定 |
|---|---|
| 名稱 | **Lumina 拾光** |
| MVP 範圍 | **P0 全部** |
| AI 照片講評（Claude vision） | 先不做，之後再加（需 serverless 後端） |
| 技術棧 | Vue 3 + Vite + Tailwind 4；手寫 service worker（同 selene，不用 vite-plugin-pwa）；suncalc 2.x 本機計算；IndexedDB 存資料；無後端 |
